# Para Ti ❤️

Una pequeña página hecha con mucho amor para **Vanessa Reyes**.

No es el regalo más caro del mundo…  
pero sí uno en el que se pusieron horas, ideas y muchísimo cariño.

---

## ✨ Sobre este proyecto

Esta experiencia interactiva nació como un regalo por el **Día de la Novia**, pensada especialmente para una relación a distancia.

Aquí no hay formularios ni botones aburridos.  
Hay estrellas, razones, una carta y un pedacito de corazón convertido en código.

Cada pantalla fue creada para que, aunque los kilómetros existan, el amor se sienta un poco más cerca.
